## Step 6:
i) Machine Learning full course from codebasics youtube: https://m.youtube.com/playlist?list=PLeo1K3hjS3uvCeTYTeyfe0-rN5r8zn9rw. I have completed this course and you can find the entire classnote named "Scikit_learning_codebasics.ipynb" inside this repo.

Learn how to use evaluation metrics like MAE, RMSE, accuracy etc. Complete every exercise in the Kaggle ML course

## Step 7:

i) StatQuest "XGBoost" playlist on YouTube

ii) Kaggle's free course on XGboost: https://kaggle.com/learn/intermediate-machine-learning

Have a clear idea on hyperparameter tuning basics including: n_estimators, learning_rate, max_depth etc.

## Step 8:
i) Kaggle's Feature Engineering course: https://kaggle.com/learn/feature-engineering 

ii) "Feature Engineering for Machine Learning" — Abhishek Thakur on YouTube

Gradually you may realize that Feature Engineering matters more than model choice.
